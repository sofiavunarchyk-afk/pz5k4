## Висновок
Під час виконання практичної роботи № 5 було успішно освоєно роботу зі структурою даних стек у середовищі Windows Forms за допомогою класу System::Collections::Generic::Stack<T>. Було практично застосовано основні методи управління стеком: додавання елементів через Push(), видалення через Pop(), перегляд вершини за допомогою Peek(), перевірку кількості елементів через Count та очищення за допомогою Clear(). Крім того, навичко-орієнтовано реалізовано фільтрацію числових даних за умовою та обробку рядків з використанням графічного інтерфейсу.
